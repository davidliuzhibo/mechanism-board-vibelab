# 机关棋阵

PICO Project Swan 的解谜游戏。一只三层的青铜机关匣，棋子不会被吃掉，只会掉到下一层；掉下去的棋子还会踩动那一层的机关。玩家要算清这条因果链，把主棋「枢」送上顶层的天枢位。

- 规则：`app/app/src/main/java/com/vrgames/jiguan/core/Board.kt`，纯逻辑，不依赖引擎。
- 关卡：同目录 `Levels.kt`，共 12 关。`src/test/.../LevelsTest.kt` 用求解器验证每关的最少步数，并确认拆掉任何一枚杵或梭、任何一根连杆或转轮都会无解。
- 关卡设计工具：`docs/solver.py`、`docs/levels.py`，规则和游戏相同，可以单独运行。
- 设计方案：`docs/机关棋阵设计方案.html`。
- 测试钩子：调试包里 `adb shell am broadcast -a com.vrgames.jiguan.TEST -p com.vrgames.jiguan --es cmd walk`，说明见 `game/AutoPilot.kt`。

## 素材
- 模型、贴图和全景图：火山方舟 Seedream 和 Seed3D 生成，提示词在工作区 `assets_lab/jiguan/`。
- 旁白：ListenHub 语音合成。
- 音乐（0.2 起）：Forgotten Tombs（kindland），CC0，https://opengameart.org/content/forgoten-tomb-ambience 。0.2 换曲的候选试听版在 `docs/音乐候选_v2/`，另两首 Asian Oriental 1/2（tozan）也是 CC0，但 Asian Oriental 2 已经是捏糖人的配乐，不要重复用。0.1 用的曲子和当时的候选在 `docs/音乐候选/`。
- 墓室道具（青铜灯、罗盘、竹简、方鼎、玉璧）：PICO SGS 生成，提示词在工作区 `assets_lab/jiguan_v2/sgs/list.tsv`。
- 音效：`tools/sfx_synth.py` 合成。
